# Fingerprint Quality Assessment

## Description
This project implements a Contactless Fingerprint Quality Assessment system using Python, OpenCV, and Streamlit. It analyzes the quality of uploaded fingerprint images and provides a quality score with recommendations.

## Features
- Fingerprint image upload
- Blur detection
- Brightness analysis
- Glare detection
- ROI coverage calculation
- Ridge clarity analysis
- Overall quality score
- PASS/FAIL decision
- Capture guidance
- Processed image visualization

## Technologies Used
- Python
- OpenCV
- NumPy
- Streamlit

## How to Run

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run quality_app.py
```
